AgéndaloTú es una aplicación de organización y productividad personal y grupal cuyo objetivo es ayudar a los usuarios a planificar su día a día, gestionar actividades y encontrar horarios adecuados para realizar eventos, ya sean individuales o en grupo.

La aplicación permite a cada usuario crear, organizar y gestionar actividades, las cuales pueden ser públicas o privadas y pueden realizarse de manera individual o involucrar a varios participantes.

Los usuarios pueden formar grupos, invitar a otros usuarios y administrar sus miembros. Dentro de estos grupos pueden organizarse actividades conjuntas, mientras que cada usuario también puede gestionar sus propias actividades personales.

#Cada actividad posee información como:

Identificador.
Título.
Descripción.
Propietario.
Visibilidad, pudiendo ser pública o privada.
Segmento de tiempo en el que se realizará.

La aplicación debe permitir establecer preferencias de disponibilidad horaria para cada usuario. Estas preferencias incluyen el día de la semana, hora de inicio, hora de finalización y una prioridad. Esto permite que el sistema tenga en cuenta los horarios en los que cada persona prefiere realizar actividades.

El sistema debe contar con un gestor de horarios capaz de analizar las actividades, participantes y disponibilidades para calcular los horarios más adecuados para realizar una actividad grupal.

Cuando existen incompatibilidades entre los horarios de los participantes, la aplicación debe detectar y registrar los conflictos, indicando qué usuario está involucrado, una descripción del conflicto y su gravedad.

A partir de este análisis, el sistema debe generar una recomendación de horario, proporcionando:

El mejor segmento de tiempo encontrado.
Posibles horarios alternativos.
Los conflictos detectados.
Tipos de actividades

La aplicación contempla dos tipos principales de actividades:

Actividad solitaria: actividad realizada individualmente por un usuario.
Actividad conjunta: actividad que involucra a varios participantes y requiere encontrar un horario compatible entre ellos.
Gestión de participantes

Los usuarios pueden actuar como participantes de actividades y recibir notificaciones. Los grupos cuentan con un propietario y una lista de miembros. El propietario puede agregar o eliminar miembros del grupo.

Además, existe el concepto de organizador, encargado de crear grupos e invitar usuarios a participar.

#Objetivo principal

El objetivo de AgéndaloTú no es simplemente funcionar como un calendario, sino ayudar activamente al usuario a decidir cuándo realizar sus actividades, especialmente cuando intervienen varias personas con diferentes disponibilidades.

##Por ejemplo:

Matías quiere organizar una sesión de estudio con tres compañeros. Cada uno tiene diferentes horarios disponibles. AgéndaloTú analiza sus disponibilidades, encuentra los segmentos de tiempo compatibles y propone un horario principal junto con alternativas. Si algún participante tiene un conflicto, el sistema lo identifica y lo muestra.
